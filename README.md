# فاتورتي (Fatoorati) - نسخة iOS 8 (iPad 4 - armv7)

## طريقة بناء ملف الـ IPA تلقائياً عبر GitHub Actions:
1. أنشئ مستودعاً (Repository) جديداً على حسابك في GitHub.
2. فك ضغط هذا الملف وارفع جميع محتوياته (بما في ذلك مجلد `.github` المخفي) إلى المستودع.
3. ادخل إلى تبويب **Actions** في المستودع، وانتظر انتهاء عملية البناء (`Build Fatoorati iOS 8 IPA`).
4. حمّل الملف الناتج من قسم **Artifacts** باسم `Fatoorati-iOS8-IPA`.
5. ثبت ملف `.ipa` على الآيباد عبر **3uTools** أو **Filza** (مع وجود **AppSync Unified**).
